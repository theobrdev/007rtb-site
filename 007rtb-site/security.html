Security Patches

How 007RTB keeps a 2007 client safe to play today

Jump to: 1. Why it needed fixing | 2. The 4 patches | 3. Map review | 4. Closed network

1. Why the original client needed fixing

The original March 2007 build (0.3.368.0) was made long before modern security protections existed. If someone runs the original, unmodified executable today, a malicious map can run commands directly on the player's Windows system (a class of flaws known as Remote Code Execution, or RCE).

2. The 4 critical flaws removed from the executable

1

Malicious bytecode blocked in loadstring

The original Lua 5.1 allowed pre-compiled bytecode to be loaded inside scripts, which could be used to escape the game's restrictions and attack the PC. The luaU_undump function was patched in Assembly so the client rejects any bytecode and accepts only plain Lua text.

2

Local file execution removed (dofile and loadfile)

These functions let a map script read or run files hidden on the player's computer. They were neutralized directly in the binary.

3

Garbage-collector escape blocked (__gc)

A classic hole in old Lua, used to run code outside the safe area when an object is cleared from memory. It was also disabled in the executable.

4

Built-in browser disabled (HtmlService)

The 2007 client used the old Internet Explorer engine to open pages inside the game, which today is an open door for malware and browser exploits. The service was blocked so that no map can open external links.

3. Cleanup and review of converted maps

Every map in the Maps Archive goes through our converter (rbx_modern_to_2007.py) and is reviewed before it is published on this site. Broken scripts, old server filters (SecurityScript) and suspicious commands are removed before publication.

4. Closed network rule (@Tester)

007RTB does not open ports to the public internet and does not accept connections from strangers. All matches happen exclusively inside the private Radmin VPN room, only between verified members with the @Tester role. Want to play? Apply for @Tester on Discord.

Important: these protections apply to the patched client distributed by this project. Do not run an unmodified 0.3.368.0 executable with maps from other sources.
